# AI-Powered YouTube Summarizer, QA Tool with RAG, LangChain, FAISS

It is a a question-answering (QA) tool capable of extracting and summarizing information from YouTube videos.

It uses LangChain and a large language model (LLM), the tool will answer specific questions based on a video's transcript. 

As it uses the IBM WatsonX AI LLM collection, requires the following environment variables set up:
- WATSONX_API_KEY
- WATSONX_URL
- WATSONX_PROJECT_ID

Alternatively the LLM and the embedding can be changed to another supplier.
